# Changelog

## 0.3.0

- Embed the five existing module diagrams in README sections covering business purpose, target flow and local implementation.

- Add disabled-by-default Bedrock/Ollama adapters, offline SDK contract tests, separate development/acceptance inputs, model release checks and session monitoring without real model inference.
- Add deterministic engineering/business quote drafting, validated cent arithmetic, version-bound internal approval and manager quantity revisions.
- Add a local Decision Workspace with queued generation, guided follow-ups, structured rejection and pending-review feedback tied to exact source versions.
- Add read-only Evaluation Studio, nine controlled faults and a separate manager-feedback/recalculation experiment.
- Make approval and feedback retries idempotent and keep same-quantity what-ifs uncommitted.
- Add the system overview to a business-focused README, simplify Evaluation Studio and provide reproducible interview walkthroughs. No live LLM integration, cloud deployment or production business uplift is claimed.

## 0.2.0

- Add synthetic delivery-risk training on the existing incremental ETL, with shared-line capacity and planning snapshots.
- Freeze quantity and delivery promises at prediction time; enforce effective, observed and availability dates and purge immature labels at temporal boundaries.
- Compare train-only logistic regression with fixed rules under the same weekly alert budget. Select alerts across all eligible orders before matching outcomes; report pending labels separately.
- Export a numeric JSON model and label-free batch inputs; verify scoring independently without installed ML packages.
- Extend regression tests, input contracts, verification evidence and GitHub Actions. Retain rules as baseline; synthetic results do not justify production promotion.

## 0.1.0

- Local incremental ETL, atomic publication, replay and fault recovery.
- Scoped lexical RAG with version/deletion/access checks and bounded document context.
- Synthetic order/email/engineering examples, fake-client Snowflake/Gmail contracts and minimal CI.
