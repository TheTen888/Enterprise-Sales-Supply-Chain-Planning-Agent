# Architecture brand assets

Source URLs are recorded in `sources.json`. The overview embeds these assets locally; it makes no browser requests to logo providers.

Simple Icons assets follow the project's CC0 icon distribution; trademark rights remain with the respective owners. Docker and Pytest marks come from Devicon. AWS service icons come from the Diagrams resource collection. Inngest and LangSmith icons come from their official site favicons. The Meta mark identifies the LlamaFirewall project; it is not a dedicated LlamaFirewall logo. Tools without a bundled icon use a colored initial and their full name rather than an invented official mark.

Framework references:

- [LlamaFirewall](https://github.com/meta-llama/PurpleLlama/tree/main/LlamaFirewall): scanner integration design; application authorization, tool schemas and privacy policy remain explicit controls.
- [IntellAgent](https://github.com/plurai-ai/intellagent): proposed synthetic conversation evaluation framework. Current recorded results come from the project's own fixtures and evaluator.

Brand badges identify the architecture's selected or proposed technologies. They do not establish a deployed integration; implementation evidence is available in each detail view.
